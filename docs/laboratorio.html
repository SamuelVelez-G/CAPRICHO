Firmar desde Python (diapositiva 19)

      
Para enviar desde Postman o un script, la firma se calcula así. La llave está en el README (variable CAPRICHO_LLAVE_HMAC).

      
import hashlib, hmac, json, urllib.request

LLAVE = b"<llave del README>"
txn = {"idTxn": 10001, "user": "aa@aa.com",
       "date": "2026-09-23T10:30:01.120",
       "value": 50000, "paymentMethod": "Tarjeta"}
datos = json.dumps(txn, sort_keys=True, separators=(",", ":"))
txn["hash"] = hmac.new(LLAVE, datos.encode(), hashlib.sha256).hexdigest()

peticion = urllib.request.Request(
    "http://127.0.0.1:5000/api/transacciones",
    data=json.dumps(txn).encode(),
    headers={"Content-Type": "application/json"})
print(urllib.request.urlopen(peticion).read().decode())
